# Age Calculator Using Python

A simple Python-based Age Calculator that calculates a user's exact age in years, months, and days based on their date of birth.

## Features
- Takes date of birth as user input.
- Calculates age in years, months, and days.
- Uses the current system date automatically.
- Validates future dates of birth.
- Simple and beginner-friendly program.

## Technologies Used
- Python
- datetime module

## Concepts Used
- Variables and data types
- User input and output
- Conditional statements
- Arithmetic operations
- Date and time handling

## Purpose
This project was developed as a beginner-level Python programming project to understand date handling, user input, and conditional statements.
